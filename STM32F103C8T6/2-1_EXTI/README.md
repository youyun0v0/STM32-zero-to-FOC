# 笔记：
## 中断
- 定义:在主程序运行过程中，出现了特定触发条件，CPU暂停当前运行程序，去处理中断程序处理完成后又返回原来被暂停的位置继续运行
- 中断优先级:可以按顺序处理多个中断
- 中断嵌套:中断程序运行时，若有更高优先级的中断源中请中断，CPU则会再次暂停，转而处理新的暂停程序，处理完成后依次返回
## 管理中断:NVIC
- 管理中断运行的顺序，相当于个“叫号系统”
### 优先级响应优先级
> “排队顺序”，优先级高的先进去看病
### 抢占优先级:抢占优先级高的可以中断嵌套
> 不等前一个病人看完，直接进去看病，看完再继续前一个病人
### 优先级的确定:优先级寄存器4位(0-15，共16个优先级)
> 数值越小优先级越高.高n位为抢占优先级，低4-n位为响应优先级。n=0,1,2,3,4称作分组n
## EXTI外部中断
### 定义
- 引脚电平变化，申请中断
- 支持上升沿，下降沿，双边沿，软件(引脚无变化，程序使用代码触发)触发
### GPIO设置
- 所有GPIO口均可以，但是相同Pin(如PA0与PB0)不可以同时触发中断
### 外部中断通道:20个
- 16个GPIO_Pin，PVD输出，RTC闹钟，USB唤醒，以太网唤醒
### 触发响应模式:中断响应，事件响应
- 中断响应:申请中断，让CPU执行中断函数
- 事件响应：不向CPU申请中断，而是触发特定事件
